# Sample extensions

Complete, loadable extension code from the extenshi.io blog tutorials — the
exact code the articles walk through, kept runnable. Load one via
`chrome://extensions` → **Developer mode** → **Load unpacked**.

| Sample | What it demonstrates | Tutorial |
|---|---|---|
| [`rec-tab/`](./rec-tab/) | Recording the current tab's video + audio in MV3: the `chrome.tabCapture` stream-ID hand-off into an offscreen document, the muted-audio fix, and saving the `.webm` via `chrome.downloads` | [Record the current tab from an MV3 extension](https://blog.extenshi.io/posts/record-current-tab-tabcapture-offscreen-mv3) |
